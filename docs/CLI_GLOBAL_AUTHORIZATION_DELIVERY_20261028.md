# CLI 全项目授权交付（2026-10-28）

新 CLI 配对默认授予全部现有及未来项目的 Local 归档读写权限，无授权到期时间；配对请求仍限时并由用户在网页核对批准。全项目授权可以归档现有任务和子任务，上传者和既有历史不改写。授权可整体撤销，不授予 Cloud、Memory 或平台管理权限。

迁移 `0036_cli_global_authorization` 为已绑定、上传身份及客户端仍有效且至少有一个未撤销旧 grant 的存量 CLI 建立独立全项目永久授权，包括已过期的旧 grant。旧批准、回执与逐项目撤销事实不变；已整体撤销的客户端不复活。用户此次明确要求全项目，故新授权覆盖过去曾单独撤销的项目。CLI 0.1.2 访问旧 profile 未列出的项目时先向服务端核验当前全项目权限，无需重新配对。
