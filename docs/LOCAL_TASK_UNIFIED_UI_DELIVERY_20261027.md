# 本地任务详情沿用原布局与统一入口

更新：2026-10-27。按用户要求，新版显式归档采用旧本地任务详情的页面布局，所有本地任务详情统一从 `/tasks/[taskId]` 进入。

## 页面与入口

- 新归档任务地址为 `/tasks/[taskId]?mode=archive&projectId=[projectId]`。项目列表、创建完成跳转共用地址生成函数，目标项目明确传入。
- 已发行 CLI 0.1.1、历史回执和书签中的 `/archives/[taskId]?projectId=...` 保持可用，页面替换地址并保留锚点。无需重新发行 CLI。
- 无 `mode` 的 `/tasks/[taskId]` 保留历史会话任务。归档类型显式选择专用数据组件；目标缺失/格式错误或类型不明时拒绝读取，不尝试另一类任务作为回退。
- 新归档详情复用原标题/操作区、项目导航、左侧固定快速导航与白色概览面板；目标与版本元数据放在概览中。
- 计划直接阅读，用例采用可展开表格，原始报告逐条折叠；保留来源、稳定标识、修订与接受时间。报告正文只在展开时渲染。
- 显式上传 Prompt、根空间/子任务选择、上传身份管理、可选子任务、版本选择、固定提交快照、任务汇总和历史保持可用，替代原先全宽面板加页签的另一套布局。

这是页面结构与路由整合，领域 §56/TMP §51 的归档合同保持。旧 SessionTask 与 LocalArchiveTask 不合并身份、不迁移或改写原始历史；API、授权、CLI、schema、Cloud 和 Memory 均无本次变更。操作继续使用既有 expected version、浏览器 journal、原 key 恢复与回执校验。提交快照显示其实际返回的归档版本及目标，不借用当前选择空间的版本。
