# ADR-031：云端 Harness 原生配置与任务预算退出

**状态：Accepted，实施和部署事实另行记录。**

## 决定

CloudTask 只描述测试对象及版本、需求、目标、流程、范围和交付。模型、推理档位和插件由云端 Harness 的原生 `sdk` profile 配置，任务不指定这些参数。项目资源授权、云端模型身份与运行环境边界仍各自独立；不复制本机个人登录、凭据或会话。

固定 SDK 0.2.1rc2 的初始化接口要求 provider 和 model。适配器从同一云端 `sdk` profile 的官方组合配置读取原生 `agent-default-model` 选择并传入初始化；不再以 HyperTest 设置覆盖模型、推理或输出 token 上限。每次 Attempt 将独立云端 profile 快照到其独立 home；它不能共享会话、工作区或私有平台凭据。操作人员通过官方 CLI 管理同一 profile，插件是否已安装或能在当前隔离范围内工作以实际配置及运行结果为准。

目前受控模型代理仅接通 DeepSeek 官方 provider；其他 provider 明确拒绝，不回退模型或绕过隔离。模型凭据仍保存在宿主代理侧。原生 profile 不等于任意网络、SSH、CI、凭据或外部写入权限。新模式当前只准工作区内测试；既有 SSH、受控 HTTPS 和外部写配置不自动扩权，须另行接入并验证独立撤权与原操作对账。

新任务未提供显式源码清单时，从两仓固定提交的私有 checkout 派生完整受控清单，再通过既有路径和凭据检查后投影到 Agent 工作区，不复制 Git 对象库。当前导出范围不能承载敏感路径、符号链接、子模块、二进制或超限内容；遇到这些情况明确阻塞，不悄悄跳过并宣称完整。派生清单来自固定源码，不声称用户逐文件批准。

新任务不接受、不生成 HyperTest 任务预算，也不以超大限额冒充无预算；不生成模型请求预留或结算。Harness 或模型服务可能有自己的限制，但平台不声称其一定提供预算。Worker 仍使用租约、fence、私有进程范围、取消和清理；Docker 以有认证且限时效的心跳维持 Attempt，心跳停止即终止，不能以该心跳替代业务完成或远端操作观察。资源隔离、项目授权和请求体安全检查不是模型选择或任务预算。

## 旧数据与恢复

已冻结的任务、历史预算、HELD、原回执和未知外部操作保留；原 key 只读对账和原 owner fencing 保持。旧冻结任务不能按旧预算重新下发，须创建关联新任务。未冻结、无 Attempt 的旧 DRAFT 在编辑或重新解析时，原操作事务移除旧预算并递增版本；先前解析不能用于下发，同一原 key 精确恢复原回执。

此决定取代领域 §51、TMP §46、技术架构 §45、ADR-019 中新任务必须冻结平台预算或由平台选择模型 / 插件的条款；这些旧条款仍解释既有冻结任务的历史和对账，不作为新任务准入规则。当前不因本决定自动重放外部操作或将 Agent 结果升级为独立证据。

## 实施边界

代码、部署、真实模型身份与用户功能验收分别记录。无网络 profile 检查、隔离回归、服务启动和健康检查不证明模型请求、子智能体、插件或项目测试成功。Harness 可用的插件和模型取决于其固定版本、已安装包、凭据和受控运行环境。
